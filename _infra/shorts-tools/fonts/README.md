# 폰트

폰트 파일은 저장소에 넣지 않는다(`.gitignore`). 아래에서 받아 이 폴더에 둔다. 영상·상업 이용 범위는 받을 때 각 배포처 라이선스로 다시 확인하고, 작품 `BRIEF.md` §3 권리 표에 적는다.

| 파일 | 용도 | 받는 곳 |
|---|---|---|
| `Pretendard-ExtraBold.otf` | 자막 | Pretendard 공식 배포처(GitHub `orioncactus/pretendard`) |
| `Gaegu-Bold.ttf` | 손글씨 카드 | Google Fonts "Gaegu" |
| `NanumPenScript-Regular.ttf` | 손글씨 카드 | Google Fonts "Nanum Pen Script" |

조립 매니페스트의 `font`·`card_font`에 이 폴더의 상대경로를 적는다.
