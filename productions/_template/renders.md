## 제작 방식

- 입력(패키지 이름·파일 수·확인)
- 나레이션(엔진·크레딧·길이·분할 방식)
- 클립(워크플로·길이·seed·채택·불합격 사유와 대응)
- 조립(컷 구성·자막·그래픽), 배경음악·효과음

## 편집·납품 검수표

- [ ] 첫 3초의 화면·질문과 결말의 답이 같은 이야기다.
- [ ] 제목·썸네일·자막·설명의 표현 강도가 팩트체크와 맞는다.
- [ ] 나레이션에 메모가 읽히지 않고, 발음·쉼·음량·자막 싱크가 자연스럽다.
- [ ] 끝 → 처음을 이어 반복 재생했다. 마무리 멘트·인사·음악 종결음이 루프를 끊지 않는다.
- [ ] 화면 속 글자는 모두 후반 합성이고 오탈자가 없다.
- [ ] 장면마다 손·얼굴·물건·조명, 시대 소품, 검은 프레임을 확인했다.
- [ ] 휴대폰 크기에서 자막과 썸네일을 읽었고 UI와 겹치지 않는다.
- [ ] 최종본의 길이·화면비·해상도·FPS·음량·SRT를 검사했다.
- [ ] 음악·폰트·목소리·그림 권리와 표시 요건, 출처 링크를 확인했다.
- [ ] 납품 파일(md5 일치)과 승인·공개 범위를 기록했다.
