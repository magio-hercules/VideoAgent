# private/ — 비공개 폴더 안내

이 폴더에는 **채널 고유 정보와 운영 기록**을 둔다. 공개 저장소에는 이 안내문(`private/README.md`)만 올라가고,
나머지 파일은 `.gitignore`로 모두 빠진다. GitHub에 백업되지 않으므로 Drive나 로컬 백업으로 따로 보관한다.

비밀 값(API 키·보이스 ID)은 여기에도 두지 않는다. 그런 값은 루트의 `.env`에 둔다(`.env.example` 참고).

## 처음 만들기

```bash
cp config/channel.example.md private/channel.md   # Windows: copy config\channel.example.md private\channel.md
```

나머지 파일은 아래 양식대로 만들어 채운다. 파일이 없어도 에이전트는 동작한다. 없으면 기본값
(`config/channel.example.md`)을 쓰거나 그 기록이 없다고 보고한다.

## 파일과 들어갈 내용

| 파일 | 필요 | 들어갈 내용 | 쓰는 단계 |
|---|---|---|---|
| `channel.md` | 권장 | 채널 이름·핸들, 한 줄 소개, 형식·길이·주기, 타깃, 목표 우선순위, 시청자에게 주는 가치, 소재 범위, 성과 지표 우선순위, 나레이션 방식, 썸네일 문구 패턴, 금지 고정 멘트, 에피소드 저장소 루트 이름, 다른 언어판 여부 | 모든 단계 |
| `decisions.md` | 권장 | 운영자 결정 기록(날짜 / 결정 / 반영 위치). 새 결정은 표 맨 위에 추가하고, 바뀐 결정은 지우지 않고 "→ 날짜 변경"을 붙인다 | 모든 단계 (AGENTS.md 권위 순서 3번) |
| `episode-index.md` | 권장 | 회차 목록(회차 / 소재 / 작업 코드 / 납품물 / 상태 / 공개일·URL). 새 주제의 중복 확인과 다음 회차 번호에 쓴다 | 1단계, 9단계 |
| `analytics.md` | 선택 | 성과 분석 방법: 지표 정의, 수집 항목, 회고 방식, 실험 설계, 수익화 조건 추적 | 11단계 (`performance` 라우트) |
| `denylist.txt` | **공개 전 필수** | 공개되면 안 되는 문자열을 한 줄에 하나씩: 채널명·핸들·보이스 이름·회사명·개인 아이디·PC 이름 등. `#`으로 시작하는 줄은 무시한다 | 커밋 전 `_infra/public-check/check_public.py` |

### `decisions.md` 양식

```markdown
| 날짜 | 결정 | 반영 위치 |
|---|---|---|
| 2026-01-01 | (예: 블록당 장면은 1~2개로 한다) | craft/doctrine/shorts-format.md §3 |
```

### `episode-index.md` 양식

```markdown
| 회차 | 소재 | 작업 코드 | 납품물 | 상태 | 공개일·URL |
|---|---|---|---|---|---|
| EP001 | (소재) | EP001 | 영상·썸네일·메타 | (제안 / 대표 선택 / 대본 승인 / 제작 중 / 납품 / 공개 확인) | (날짜·URL) |
```

상태 용어는 `craft/doctrine/production-cycle.md` §3을 따른다.

### `analytics.md`에 둘 절

1. 지표 — 우선순위, 각 지표의 정의·계산·Studio 위치
2. 수집 — 공개 후 24시간·7일·28일에 받을 항목
3. 회고 — 편별·주간 회고 순서
4. 실험 설계 — 한 번에 한 변수, 실험 로그 항목, 판정 기준
5. 수익화 조건 추적 — 확인일을 붙인 플랫폼 조건과 주간 기록 항목

편별 성과 수치는 이 파일이 아니라 그 작품의 `renders.md` 성과 절에 적는다.

### `denylist.txt` 예

```text
# 채널·개인 식별 문자열 (대소문자 구분 없음)
MyChannelName
@my.handle
MyVoiceName
```

## 지킬 것

- 이 폴더의 값을 공개 문서·코드·커밋 메시지에 복사하지 않는다. 공개 문서는 이 폴더의 **파일 경로만** 가리킨다.
- 이 안내문은 공개되므로 실제 값을 적지 않는다.
- 다른 작업 공간(Claude 프로젝트 등)에 정본이 있으면 그쪽을 먼저 고치고 이 폴더의 사본을 맞춘다.
