# 채널 설정 (예시) — `private/channel.md`의 공개용 기본값

이 파일은 채널 고유 값의 **양식과 기본값**이다. 실제 값은 `private/channel.md`(Git 제외)에 같은 항목으로 적는다.
에이전트는 `private/channel.md`가 있으면 그것을, 없으면 이 파일을 쓴다. 비밀 값(보이스 ID·키)은 여기에도 쓰지 않고 `.env`에 둔다.

| 항목 | 값 |
|---|---|
| 채널 이름 / 핸들 | (예: 나의 지식 쇼츠 / @my.channel) |
| 한 줄 소개 | (예: 익숙한 것들의 유래와 기원) |
| 형식 | YouTube Shorts 9:16, 얼굴 없는 반말 다큐 나레이션 + 자막 |
| 길이 | 1~4분 안에서 주제를 가장 잘 설명하는 분량 |
| 주기 | 주 2~3편 |
| 타깃 | (예: 20~60대 한국어권) |
| 목표 우선순위 | (예: 수익화 > 브랜드 인지도 > 정보 전달) |
| 시청자에게 주는 가치 | (예: 정보 > 재미 > 논쟁거리) |
| 소재 | 익숙한 말·음식·물건·관습·이름. 시작의 이유, 해결한 문제, 바뀐 과정, 보급의 계기 중 하나를 중심에 둔다 |
| 성과 지표 우선순위 | 조회수 > 구독 전환 > 리텐션 > 댓글 |
| 나레이션 | 힉스필드 Eleven v4 + 운영자 보이스 (`.env`의 `NARRATION_VOICE_*`) |
| 썸네일 문구 패턴 | "주제의 ○○○" |
| 금지 고정 멘트 | (채널 슬로건 등, 영상 끝에 넣지 않을 문구) |
| 에피소드 저장소 루트 | (예: Google Drive `MyChannel/`) |
| 다른 언어판 | (예: 보류) |
