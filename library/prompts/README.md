# 프롬프트 라이브러리

재사용할 프롬프트 파일의 규칙과 모델 색인을 소유한다.

## 파일 규칙

- 위치: `library/prompts/{모델}/{이름}.md`
- 파일 첫머리에 대상 모델, 용도, 검증 여부(검증됨/미검증)를 적는다.
- 작품 하나에만 쓰는 프롬프트는 작품 폴더 `prompts/`에 둔다(공개 대상 아님).
- 모델 문법 자체는 `craft/playbooks/{모델}.md`에 둔다 (여기에 복사하지 않음).
- 채널·작품을 알아볼 수 있는 문장은 넣지 않는다. `{…}` 자리표시로 둔다.
