# 플레이북 색인

모델·작업별 프롬프트 문법과 반복 특성은 한 파일(`craft/playbooks/{이름}.md`)이 소유한다.
새 교훈은 작품의 `renders.md`에 먼저 쓰고, 두 편 이상에서 반복되면 여기로 옮긴다.

## 새 플레이북 규칙

- 사용자가 확인했거나 실제 결과로 검증한 문법·특성만 적는다. 아직 시험하지 않은 것은 **(미검증)**으로 표시한다.
- 샘플러·해상도·길이 같은 수치는 확인된 값만, 확인한 날짜와 함께 적는다.
- 특정 작품·채널을 알아볼 수 있는 표현(편 번호·주제명)은 쓰지 않는다. 현상과 대응만 적는다.
- 추가하면 아래 표에 한 줄 등록한다.

| 대상 | 파일 | 용도 |
|---|---|---|
| MiniMax H3 R2V | `minimax-h3-r2v.md` | 쇼츠 클립 (대표 그림 → 영상). 불합격 대응 순서 포함 |
| MiniMax H3 I2V + 터보 | `minimax-h3-i2v-turbo.md` | 구도 유지가 중요한 클립 |
| Z-Image Turbo | `z-image-turbo.md` | 정지 컷·보조 그림, 그림 정리 요령 |
| GPT 이미지 | `gpt-image.md` | 스타일 시안·대표 그림·썸네일 바탕 |
| 후반 작업 | `post-production.md` | 나레이션·받아쓰기·조립·배경음악 |
