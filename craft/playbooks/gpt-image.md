# GPT 이미지 플레이북 — 스타일 시안·대표 그림·썸네일 바탕

이 문서는 GPT 이미지 모델로 **스타일 비교 시안, 블록별 대표 그림, 썸네일 바탕 그림**을 만드는 방법을 소유한다.
그림 조건은 `craft/doctrine/shorts-format.md` §3, 누가 어느 단계를 맡는지는 `craft/doctrine/production-cycle.md` §1.

기준일: 2026-11-11

## 생성 경로

**기본 경로: Codex CLI 내장 이미지 생성(`image_gen`).** 도구 `_infra/codex-imagegen/codex_imagegen.py`로 부른다(사용법·조건 → 그 폴더 `README.md`).
ChatGPT 계정 로그인을 쓰고 API 키나 힉스필드 크레딧은 쓰지 않는다. 2026-11-11 시험에서 생성·참조 그림·한글 프롬프트가 동작했다.

| 단계 | 담당 | 경로 |
|---|---|---|
| 4 스타일 시안 · 5 대표 그림 | ChatGPT 쪽 (Codex) | Codex `image_gen`. Codex 세션 안에서 직접 만들거나 도구로 부른다 |
| 9 썸네일 바탕 | Claude | 도구 `codex_imagegen.py` |

- Codex 세션 안에서 직접 만들 때도 결과는 `~/.codex/generated_images/<세션>/`에 저장되므로, **고른 그림을 아래 파일명으로 작품 폴더에 복사**해야 한다. 도구를 쓰면 이 복사를 대신 해 준다.
- 어느 경로든 **파일명과 저장 위치는 같다**(아래 §스타일 비교·§대표 그림). 인계 검사가 이 이름으로 그림을 찾는다.
- 쓰는 프롬프트는 그림 옆 `prompts/` 폴더에 `.txt`로 남긴다(예: `05_제작/대표이미지/prompts/<EP>_B01.txt`). 도구의 `--prompt-file` 입력 겸 기록이다.
- 대체 경로: Codex를 쓸 수 없으면 ① ChatGPT 앱에서 기준 그림을 첨부해 만들고 같은 파일명으로 저장하거나, ② 힉스필드 `gpt_image_2_6`(같은 GPT Image 계열, 크레딧 승인 절차 → `docs/runbooks/paid-generation.md`)을 쓴다. ②는 대표가 지시할 때만 쓴다.

## 기본값

| 항목 | 기준 |
|---|---|
| 모델 | GPT Image 계열 (ChatGPT 이미지 생성) |
| 비율·해상도 | 9:16 세로. 프롬프트에 `vertical 9:16 portrait`를 넣는다. Codex 결과는 941×1672(시험 기준). ComfyUI 입력용 768×1344는 6단계에서 Claude가 따로 만든다 |
| 참조 | 기준 그림을 첨부해 화풍·인물을 맞춘다 (도구는 `--ref`, Codex 세션은 이미지 첨부, 앱은 업로드) |
| 장수 | 도구 한 번에 1~4장. 블록이 다르면 블록마다 따로 부른다(장면 문장이 다르므로) |
| 프롬프트 | 공통 스타일 문장(4단계에서 고정) + 블록 장면 문장 + `no text, no letters, no numbers, no logos` |
| 사용량 | ChatGPT 요금제 사용량을 쓴다. 생성 전에 장수를 알리고 승인받는다. 실패해도 자동으로 다시 만들지 않는다 |
| 기록 | 장수·경로·채택 여부를 `renders.md`에 적는다 |

## 스타일 비교 (4단계)

- 갈등이나 핵심 전환이 가장 잘 보이는 블록 **하나**를 3~5화풍으로 동시에 만든다.
- 같은 장면 문장에 화풍 문장만 바꾼다. 피사체·비율·구도·정보량은 맞춘다.
- 결과를 한 장의 비교 시트로 묶어 보여 주고, 모든 시안을 작품 폴더 `04_화면설계/스타일_시안/`에 저장한다. 대표가 고른 기준 그림은 `04_화면설계/`에 둔다.

## 대표 그림 (5단계)

- 블록마다 한 장. 파일명 `<EP>_Bxx_representative.png`(분할 블록은 `<EP>_B02a_representative.png`), 저장 위치 작품 폴더 `05_제작/대표이미지/`. 인계 뒤 Claude가 에피소드 저장소에 올린다.
- 검수: 글자·글자 모양 낙서, 손·얼굴·물건 개수, 시대 소품, 인물·색 일관성. 불합격 장면만 다시 만든다.
- 대체: 단순 화풍 시안은 PC가 켜져 있으면 로컬 Z-Image Turbo도 가능(→ `z-image-turbo.md`).

## 썸네일 바탕 (9단계, Claude)

- 대표 그림을 바탕으로 쓰거나 같은 스타일로 새로 만든다. 문구는 그림에 넣지 않고 후반에 합성한다.
- 새로 만들 때는 도구 `codex_imagegen.py`로 대표 그림을 `--ref`로 붙여 만든다. 생성 전에 장수를 알리고 승인받는다.
- 2K 이상 큰 해상도가 꼭 필요하면 대표 지시로 힉스필드 `gpt_image_2_6`을 쓴다(견적·승인 → `paid-generation.md`).
