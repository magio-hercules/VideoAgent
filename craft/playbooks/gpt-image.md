# GPT 이미지 플레이북 — 스타일 시안·대표 그림·썸네일 바탕

이 문서는 GPT 이미지 모델로 **스타일 비교 시안, 블록별 대표 그림, 썸네일 바탕 그림**을 만드는 방법을 소유한다.
비용 승인 절차는 `docs/runbooks/paid-generation.md`, 그림 조건은 `craft/doctrine/shorts-format.md` §3.

기준일: 2026-11-10

## 기본값

| 항목 | 기준 |
|---|---|
| 모델 | 힉스필드 MCP `gpt_image_2_6` (ChatGPT와 같은 GPT Image 계열) |
| 비율·해상도 | 9:16, 2K. ComfyUI 입력용 768×1344는 6단계에서 따로 만든다 |
| 참조 | 기준 그림을 참조(medias)로 넣어 화풍·인물을 맞춘다 |
| 프롬프트 | 공통 스타일 문장(4단계에서 고정) + 블록 장면 문장 + `no text, no letters, no numbers, no logos` |
| 생성 | 일괄 생성(`generate_image_batch`, 최대 12개씩) |
| 비용 | 생성 전에 `get_cost`로 확인해 알리고 승인. 실측: 2K·high 장당 약 2.75크레딧 → 4화풍 비교 약 11크레딧 |

## 스타일 비교 (4단계)

- 갈등이나 핵심 전환이 가장 잘 보이는 블록 **하나**를 3~5화풍으로 동시에 만든다.
- 같은 장면 문장에 화풍 문장만 바꾼다. 피사체·비율·구도·정보량은 맞춘다.
- 결과를 한 장의 비교 시트로 묶어 보여 주고, 모든 시안을 에피소드 폴더 `04_화면설계/스타일_시안/`에 저장한다.

## 대표 그림 (5단계)

- 블록마다 한 장. 파일명 `<EP>_Bxx_representative.png`, 저장 위치 에피소드 폴더 `05_제작/대표이미지/`.
- 검수: 글자·글자 모양 낙서, 손·얼굴·물건 개수, 시대 소품, 인물·색 일관성. 불합격 장면만 다시 만든다.
- 대체: 운영자가 ChatGPT에서 직접 만든 그림을 주면 그대로 쓴다. 단순 화풍 시안은 로컬 Z-Image Turbo도 가능(→ `z-image-turbo.md`).

## 썸네일 바탕 (9단계)

- 대표 그림을 바탕으로 쓰거나 같은 스타일로 새로 만든다. 문구는 그림에 넣지 않고 후반에 합성한다.
