# 쇼츠 제작 표준 — 사양·연출·판정 기준

이 문서는 모든 편에 공통인 **제작 기준**을 소유한다. 편마다 다른 값(목표 길이, 스타일, 강조색)은
그 편의 `BRIEF.md`와 판정 기준에서 정한다. 단계·승인은 `craft/doctrine/production-cycle.md`,
실패 대응은 `craft/playbooks/`를 따른다. 채널 고유 값은 `private/channel.md`.

기준일: 2026-11-10

---

## 1. 기술 사양

| 항목 | 기준 |
|---|---|
| 화면 | 1080×1920 세로, 24fps(H3 출력 기준, 편에 따라 30fps). FPS를 바꾸면 떨림·싱크 확인 |
| 코덱 | H.264(yuv420p, BT.709) + AAC 48kHz |
| 음량 | 통합 −16 LUFS ±1, 트루피크 −1 dBFS 이하 |
| 나레이션 대 BGM | 약 17~20dB (BGM 단독 −33~−35 LUFS) |
| 길이 | 1~4분 안에서 주제를 가장 잘 설명하는 분량. 편별 판정 기준에서 범위를 정한다 |
| 길이 일치 | 영상과 오디오 길이 차 ±0.05초 이내 |
| 루프 | 끝 프레임이 첫 프레임으로 자연스럽게 이어진다 |
| 납품물 | 최종본, 썸네일, 업로드 정보, 자막 SRT(선택) |
| 납품 확인 | PC·클라우드 md5 일치 |

## 2. 대본

- **톤과 흐름:** 반말 다큐 톤. 훅(질문) → 흔한 속설 → 반박·근거 → 진짜 유래 → 회수(첫 질문에 답).
- **블록:** 블록 = 나레이션 한 턴 = 화면 장면 1~2개. 블록마다 핵심 정보는 하나만 둔다.
- **사실 등급:**

| 등급 | 기준 | 대본에서 |
|---|---|---|
| 확인 | 1차 자료 또는 독립 출처 2개 이상 | 그대로 쓴다 |
| 전언 | 출처는 있으나 확정할 수 없음 | "~라고 전해진다", "~라는 설이 있다" |
| 미확인 | 출처 없음 | 본문에서 빼고 설명란에 "여러 설"로만 쓴다 |

- **TTS 원고와 자막 원고를 따로 둔다:**

| | TTS 원고 | 자막 원고 |
|---|---|---|
| 숫자·약자 | 한글 읽기(천팔백구십일 년, 에스오에스) | 아라비아 숫자·원래 표기 |
| 따옴표 | 뺀다 | 원래대로 |
| 쉼 | 쉼표나 '…'로 지시 | — |

- **문장 잇기:** 마침표보다 쉼표로 이어 쓴다.
- **길이 계산:** 대본 승인 때 예상 길이를 함께 보여 준다. Eleven v4 한 테이크 실측은 약 5.2~7.5음절/초이고, 가안보다 20~30% 짧게 나오는 경우가 많다.
- **루프 문장:** 마지막 문장이 질문에 답한 뒤 첫 문장·첫 장면으로 이어지게 쓴다.
- **고정 마무리 멘트 금지:** 채널 슬로건 같은 고정 멘트, 인사, 정형 구독 멘트, 음악 종결음을 끝에 넣지 않는다. 루프를 끊는다. 대표가 회차에서 고른 질문형 결말은 그 대본을 따른다.
- **초반:** 0~3초에 사물·행동·모순과 질문을 전달하고, 10~15초 안에 첫 단서를 준다.
- **각색 금지:** 실제 발언이나 기록을 지어내지 않는다. 제목·썸네일·자막도 대본과 같은 확신도를 지킨다(→ factcheck-rights §3).
- **대본 평가 배점:** 신규 진입 30, 이야기 전개 25, 정보 가치 20, 근거·표현 15, 채널 적합성 10(→ planning §3).

## 3. 비주얼

- **스타일:**
  - 편마다 하나를 정하고, 편 안에서는 바꾸지 않는다. 같은 핵심 장면을 3~5화풍으로 비교해 대표가 고른 그림을 기준 이미지로 보존한다(→ planning §4).
  - 채널 아트(팔레트·심볼)와 영상 화풍은 따로 관리한다.
  - 사용해 본 화풍: 화이트보드 두들, 파스텔 두들, 종이 콜라주, 종이 디오라마, 민화풍 콜라주, 색연필, 수채, 시네마틱 실사 톤.
- **장면 수:** 블록당 장면 1~2개, 임팩트 있는 장면 위주. 장면 안의 변화는 클립의 작은 동작, 편집 줌, 그래픽으로 만든다. 한 그림이 15초 넘게 이어지면 접사나 두 번째 클립을 넣는다.
- **그림 속 글자 금지:** 그림 안에 글자를 생성하지 않는다. 글자·숫자·라벨은 모두 후반 그래픽으로 넣는다. 글자처럼 보이는 낙서(나선, 라벨 선)도 검사해 지운다.
- **색:** 톤다운한다. 화이트보드 계열은 얇은 마커 선, 흰 바탕, 파스텔 포인트 소량. 그 밖의 화풍은 파스텔 계열로 맞춘다.
- **구도:** 피사체는 화면 위쪽 약 60% 안에 크게 둔다. 세로 구도를 쓴다. 연표나 행렬은 위아래로 배치한다.
- **안전 영역:** 하단 약 20%와 오른쪽 버튼 열(x > 0.86, 높이 45~85%)에 핵심 피사체·칩·자막을 두지 않는다.
- **캐릭터 기준 그림:** 캐릭터가 나오는 편은 기준 그림 한 장을 정해 모든 컷의 참조에 넣는다.

## 4. 클립

- **카메라:** 생성에서는 고정한다. 콘티의 밀기·당기기·팬은 조립 단계 편집 줌으로 만든다.
- **동작:** 작게, 한 가지씩 지시한다.
- **프롬프트:** 모델별 형식은 `craft/playbooks/`. 고정 문장에는 그 키프레임에 **실제로 그려진 것만** 쓴다.
- **참조 그림 우선:** 참조 그림이 프롬프트보다 강하다. 모양을 바꾸려면 그림을 고친다.
- **검수:** 6~8프레임 접촉 시트를 만들고, 필요한 구간은 확대해 본다. 볼 것: 모핑, 사물 생성·소멸, 색·밝기 변화, 글자 생성, 좌우 검은 띠.

## 5. 나레이션

- **엔진·보이스:** 힉스필드 `elevenlabs_v4` + 운영자 보이스. 보이스 이름·ID는 `.env`의 `NARRATION_VOICE_*`(→ `.env.example`).
- **생성 방식:** 대본 전체를 블록 = 턴인 dialogue 한 테이크로 만든다.
- **크레딧:** 생성 전에 예상 크레딧을 알리고 승인받는다(실측 편당 약 2~10크레딧).
- **대조:** Whisper medium으로 원고와 맞춰 본다. 다르게 받아 적힌 곳은 청취로 판단한다.
- **블록 분할:** 앞 단어 끝 −0.45초 ~ 다음 단어 시작 +0.15초 구간에서 가장 긴 무음의 가운데에서 자른다. 블록 뒤 쉼은 0.3~0.5초.
- **길이 맞추기:** 속도 변경으로 길이를 맞추지 않는다. 꼭 필요하면 rubberband 0.93배 이내(포먼트 보존)까지만.

## 6. 자막·그래픽

### 자막

| 항목 | 기준 |
|---|---|
| 글꼴 | Pretendard ExtraBold 60~64px |
| 모양 | 반투명 띠 + 외곽선 |
| 위치 | y 0.715~0.745, 폭 860px 이하 |
| 길이 | 한 줄 12~16자, 최대 2줄. 말 속도와 실제 읽을 시간으로 조정 |
| 강조어 | 편마다 정한 색 |
| 문구 | 원고 그대로. **줄 끝 쉼표 없음**, 숫자는 아라비아 숫자 |
| 시각 | Whisper 단어 시각 + 원고 문자 정렬. **블록 첫 줄은 블록 시작에 고정** |
| 검사 | 나레이션 소리가 나는데 자막이 없는 프레임 0개 |

### 그래픽

- 칩·카드·잉크 마크는 해당 단어가 나오는 순간에 등장한다. 라벨은 그 순간의 나레이션 단어와 같아야 한다.
- 확인 안 된 설은 '전해지는 유래설', '미확인' 같은 표지와 물음표를 붙이고 단정하지 않는다.
- 재현 그림과 설명 그래픽에는 필요하면 '재현', '설명 그래픽' 표기를 붙인다.
- 화면 CTA는 넣지 않는다. CTA는 고정 댓글로 한다.

## 7. 소리

- **배경음악:** ACE-Step 1.5로 seed 2개 이상 만든다. LRA가 낮고(약 5 이하) 무음·페이드 구간이 없는 것을 고른다. 영상 전 구간에 깔고, 덕킹 4.5~5dB + 0.45초 홀드. 대안: `_infra/shorts-tools/bgm_synth.py`(코드 합성 루프).
- **효과음:** 합성음(종이 스침, 탭, 마커, 팝)을 −24~−27dB로, 말을 덮지 않게 한다.
- **H3 클립 오디오:** 기본으로 쓰지 않는다. 쓸 때는 말소리가 없는지 확인하고 −34dB 이하로 넣는다.
- **무음:** 0.6초 넘는 완전 무음을 두지 않는다. 블록 사이에도 BGM이 깔리게 한다.

## 8. 썸네일

- **안 수:** 서로 다른 진입 질문의 4종과 비교 시트(추천 1 + 대안 3, 각 선택 이유). 9:16 JPG(q92). 최종 선택은 대표. 예상 반응은 실제 클릭 성과와 구분한다.
- **문구:** "주제의 ○○○" 패턴(예: ○○의 진짜 유래, ○○의 숨은 한 글자). 2행 핵심어는 강조색 칩. 채널이 다른 패턴을 쓰면 `private/channel.md`를 따른다.
- **배치:** 핵심 문구는 위쪽 6~30%, 그림은 아래쪽.
- **단정 금지:** 설이나 의역은 물음표나 표지로 표시한다.
- **별도 이미지:** 영상 안 프레임이 아닌 썸네일은 업로드 때 직접 올려야 한다는 점을 업로드 정보에 적는다.
